# Hashimoto, a doença silenciosa

Site de storytelling com dados sobre a tireoidite de Hashimoto, feito para o Projeto A2 (Parte 2).

Quantas pessoas têm sinais de autoimunidade na tireoide sem saber? O site responde com dados de 8.699 adultos da NHANES (CDC/NCHS, Estados Unidos), ciclos 2007–2012.

- **Autora:** Julia Alcântara Ferraz Teixeira
- **Dados:** NHANES 2007–2012, arquivos THYROD, DEMO, MCQ e BMX — https://wwwn.cdc.gov/nchs/nhanes/
- **Análise exploratória (Parte 1):** notebook no Google Colab

O site é uma única página (`index.html`), sem dependências para instalar.
